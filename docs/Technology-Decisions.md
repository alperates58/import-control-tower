# Teknoloji Kararları

- .NET 10 LTS seçildi; uzun destek süresi nedeniyle yeni kurumsal proje için .NET 8 yerine tercih edildi.
- React 19.2 güncel kararlı seri olarak seçildi.
- PostgreSQL 18 desteklenen güncel ana sürüm olarak seçildi.
- Docker Compose hem yerel hem Coolify dağıtımında tek kaynak doğrusu olacak.
- Coolify, GitHub App ile private repository ve otomatik deployment kullanacak.
- Gemini 3.6 Flash, kod üretimi ve hızlı agentic döngüler için kullanılacak; ancak her faz test ve insan incelemesiyle kapatılacak.

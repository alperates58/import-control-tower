# Kapsam

## MVP kapsamı

- Kullanıcı, rol ve yetki yönetimi
- Excel şablonu indirme ve Excel import
- Import önizleme, doğrulama, hata raporu, idempotent tekrar import
- Satın alma siparişi ve sipariş kalemleri
- İthalat dosyası oluşturma
- Satın alma iş akışı
- İthalat operasyon iş akışı
- Sevkiyat ve konteyner kaydı
- Planlanan/gerçekleşen tarihler
- Görevler, son tarihler ve sorumlular
- Belge yükleme ve belge kontrol listesi
- Timeline ve audit log
- Dashboard ve filtrelenebilir operasyon listesi
- E-posta/in-app bildirim altyapısının temeli
- Docker Compose ile yerel çalışma
- GitHub üzerinden Coolify otomatik deployment

## MVP dışında

- AIS harita entegrasyonu
- Carrier/container API entegrasyonu
- Mikro ERP doğrudan bağlantısı
- Otomatik üretim riski hesaplama
- WhatsApp/Teams entegrasyonu
- Tam maliyet dağıtımı
- Mobil native uygulama
